## Padrão adotado

Cada tela documentada inclui:

- objetivo da página;
- o que existe na interface;
- principais ações do usuário;
- seção "Como fazer";
- seção "Perguntas e respostas";
- links diretos no domínio final `https://admin.standdigital.com.br` quando aplicável.
