# Equipe interna

URL principal: `https://admin.standdigital.com.br/config/users`

## Objetivo da tela

Gerenciar os acessos internos do painel para perfis administrativos, marketing e comercial.

## O que existe na tela

- cabecalho com total de usuarios e distribuicao por `Admin`, `Marketing` e `Comercial`;
- campo de busca por nome ou email;
- filtros adicionais de status e foto de perfil;
- botao `Adicionar Usuario`;
- grade com avatar, nome, email, funcao, status e acoes;
- acoes por linha para visualizar, editar, ativar, desativar e excluir;
- acoes em lote para ativar, desativar ou excluir;
- dialogo de cadastro de usuario;
- dialogo de detalhes do usuario.

## Como usar

1. Use a busca para localizar um integrante da equipe.
2. Aplique filtros se quiser restringir por status ou foto.
3. Clique em `Adicionar Usuario` para criar um novo acesso.
4. Use as acoes da grade para manter os usuarios existentes.

## Como fazer

### Adicionar um novo usuario interno

1. Acesse `https://admin.standdigital.com.br/config/users`.
2. Clique em `Adicionar Usuario`.
3. Informe o email.
4. Defina a funcao, quando essa opcao estiver disponivel.
5. Preencha os dados pessoais.
6. Conclua o cadastro.

### Enviar recuperacao de senha para um usuario

1. Localize o usuario na lista.
2. Clique em editar.
3. Use a opcao `Enviar e-mail de recuperacao`.
4. Confirme a operacao.

### Desativar um usuario

1. Localize o registro na grade.
2. Clique na acao de desativar.
3. Confirme se a sua operacao exigir validacao adicional.

### Consultar os detalhes de um usuario

1. Clique em visualizar na linha desejada.
2. Revise email, nome, funcao, status e data de criacao.

## Perguntas e respostas

### Quais perfis aparecem nesta tela?

A interface foi preparada para perfis administrativos, marketing e comercial.

### Posso editar a senha diretamente?

Nao. No modo de edicao, a tela usa fluxo de recuperacao por e-mail.

### Existe protecao para usuarios administrativos sensiveis?

Sim. Perfis mestres possuem restricoes de acao na grade para evitar alteracoes indevidas.

### Posso cadastrar varios usuarios de uma vez?

Nesta tela, o fluxo principal e individual, por cadastro de usuario.
