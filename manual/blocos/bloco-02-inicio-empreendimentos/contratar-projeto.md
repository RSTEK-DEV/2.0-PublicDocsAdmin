# Contratar projeto

URL principal: `https://admin.standdigital.com.br/standDigital/contrate`

Links contextuais relacionados:

- Contratar projeto: `https://admin.standdigital.com.br/standDigital/contrate`
- Empreendimentos: `https://admin.standdigital.com.br/standDigital`

## Objetivo da tela

Orientar a contratacao comercial de expansao do ambiente para liberar novos projetos.

## O que existe na tela

- destaque visual `Novo projeto sob contratacao`;
- titulo comercial sobre vendas imobiliarias;
- texto explicando que a criacao de novo projeto depende de contratacao;
- botao `Contratar via WhatsApp`;
- botao `Voltar para empreendimentos`;
- card lateral indicando `+1 projeto`;
- cards de beneficios, como tours 360, plantas humanizadas, vendas em tempo real e compartilhamento facil.

## Como usar

1. Abra a tela quando precisar solicitar mais um projeto para a empresa.
2. Clique em `Contratar via WhatsApp`.
3. O sistema abre o canal comercial com uma mensagem pronta.
4. Se quiser apenas retornar, use `Voltar para empreendimentos`.

## Como fazer

### Solicitar a contratacao de um novo projeto

1. Acesse `https://admin.standdigital.com.br/standDigital/contrate`.
2. Clique em `Contratar via WhatsApp`.
3. Continue o atendimento no canal comercial aberto pelo sistema.

### Voltar para a lista de empreendimentos

1. Na mesma tela, clique em `Voltar para empreendimentos`.
2. O painel retorna para `https://admin.standdigital.com.br/standDigital`.

## Perguntas e respostas

### Essa tela cria o projeto diretamente?

Nao. Ela inicia o contato comercial para liberar a expansao do ambiente.

### Quando devo usar essa tela?

Quando a empresa precisa contratar mais um projeto ou ampliar a operacao.

### O que acontece se o WhatsApp comercial nao estiver configurado?

O painel informa que o WhatsApp comercial nao esta configurado.

### Essa tela substitui o formulario de novo empreendimento?

Nao. Ela atende o fluxo comercial. O formulario de criacao direta continua sendo a tela `Novo empreendimento` para quem tem permissao.
