# Bloco 02 - Inicio da operacao e empreendimentos

Status: concluido

## Escopo

Este bloco cobre a porta de entrada da operacao de empreendimentos, incluindo a listagem dos projetos existentes, a criacao de um novo projeto e a tela comercial de contratacao.

## Telas documentadas

- [Empreendimentos](./empreendimentos.md)
- [Novo empreendimento](./novo-empreendimento.md)
- [Contratar projeto](./contratar-projeto.md)

## Resultado do bloco

O usuario consegue:

- localizar e filtrar os empreendimentos da empresa ativa;
- abrir a edicao de um empreendimento existente;
- copiar a URL publica de um empreendimento;
- entender quando a criacao direta de projeto esta liberada;
- criar um novo projeto com identificacao e localizacao iniciais, quando possuir perfil master;
- seguir o fluxo comercial de contratacao quando a expansao do ambiente for necessaria.

## Observacoes de uso

- a listagem de empreendimentos usa filtros por busca, pais e estado;
- a criacao direta de projeto fica restrita ao perfil master;
- usuarios sem permissao de criacao recebem um fluxo orientado para contratacao comercial;
- apos criar o projeto, o sistema pede a definicao de plano e status do stand antes do retorno para a listagem.
