# Playbooks

URL principal: `https://admin.standdigital.com.br/standDigital/playbooks/<id-do-empreendimento>`

Link contextual relacionado:

- Playbooks: `https://admin.standdigital.com.br/standDigital/playbooks/<id-do-empreendimento>`

## Objetivo da tela

Criar roteiros de atendimento guiados para apoiar corretores durante o processo comercial.

## O que existe na tela

- titulo `Playbooks`;
- botao `Novo Playbook`;
- painel esquerdo com lista de roteiros;
- selo `ATIVO` no roteiro publicado como principal;
- acoes para ativar, renomear e excluir;
- painel direito com editor de passos;
- botao `Preview`;
- botao `Salvar passos`;
- seletor de cenario;
- lista de passos do fluxo;
- botao para adicionar passo;
- dialogo para criar em branco ou usar modelo pronto;
- dialogo de escolha de modelos;
- dialogo para criar ou editar nome e descricao;
- dialogo de confirmacao de exclusao.

## Como usar

1. Crie um novo playbook.
2. Escolha iniciar em branco ou a partir de um modelo.
3. Edite os passos no painel da direita.
4. Salve os passos.
5. Ative o roteiro desejado quando ele estiver pronto.

## Como fazer

### Criar um playbook do zero

1. Acesse `https://admin.standdigital.com.br/standDigital/playbooks/<id-do-empreendimento>`.
2. Clique em `Novo Playbook`.
3. Escolha `Criar em branco`.
4. Informe nome e descricao.
5. Adicione os passos do roteiro.
6. Clique em `Salvar passos`.

### Criar um playbook a partir de modelo

1. Clique em `Novo Playbook`.
2. Escolha `Usar modelo pronto`.
3. Filtre ou pesquise um modelo.
4. Revise a previa dos passos.
5. Clique em `Usar este modelo`.
6. Ajuste o conteudo no editor e salve.

### Ativar um playbook

1. Na lista da esquerda, localize o roteiro desejado.
2. Clique no botao de ativacao.
3. Aguarde a confirmacao.

### Editar o fluxo por cenario

1. Selecione o playbook.
2. No editor, use o seletor de `Cenario`.
3. Revise os passos universais e os condicionais.
4. Salve os passos depois da edicao.

## Perguntas e respostas

### Posso ter mais de um playbook cadastrado?

Sim. A tela foi feita para listar varios roteiros.

### O que significa o selo ATIVO?

Ele identifica o playbook atualmente ativo para o empreendimento.

### Existe visualizacao previa no celular?

Sim. O editor possui acao de `Preview`.

### Posso começar com um modelo pronto?

Sim. A tela oferece biblioteca de modelos e filtros por categoria.
