# Pagina nao encontrada

URL principal: `https://admin.standdigital.com.br/rota-invalida`

## Objetivo da tela

Informar que a rota acessada nao existe ou nao esta disponivel no painel.

## O que existe na tela

- destaque visual do erro `404`;
- mensagem `Pagina nao encontrada`;
- explicacao de que o endereco nao existe, foi movido ou nao esta disponivel;
- botao `Ir para o inicio`;
- botao `Voltar`;
- painel lateral ilustrativo em telas maiores.

## Como usar

1. Revise se a URL acessada esta correta.
2. Use `Ir para o inicio` para retornar ao painel.
3. Use `Voltar` se quiser retornar ao passo anterior da navegacao.

## Como fazer

### Retornar ao painel principal

1. Clique em `Ir para o inicio`.
2. Acesse novamente uma area valida pelo menu principal.

### Voltar para a pagina anterior

1. Clique em `Voltar`.
2. Se nao houver historico suficiente, a aplicacao redireciona para a pagina inicial.

## Perguntas e respostas

### Esse erro significa falta de permissao?

Nao. Aqui o problema e a rota invalida ou indisponivel, nao o perfil de acesso.

### A tela sempre mostra a mesma URL?

Nao. Ela aparece como fallback para qualquer rota inexistente.
