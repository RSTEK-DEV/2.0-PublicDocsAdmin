# Meu perfil

URL principal: `https://admin.standdigital.com.br/config/meu-perfil`

Links contextuais relacionados:

- Perfil geral: `https://admin.standdigital.com.br/config/meu-perfil?tab=overview&focus=perfil-overview`
- Dados pessoais: `https://admin.standdigital.com.br/config/meu-perfil?tab=overview&focus=perfil-dados-pessoais`
- Foto do perfil: `https://admin.standdigital.com.br/config/meu-perfil?tab=overview&focus=perfil-foto`
- Seguranca: `https://admin.standdigital.com.br/config/meu-perfil?tab=overview&focus=perfil-seguranca`

## Objetivo da tela

Permitir que o proprio usuario mantenha seus dados pessoais, foto e senha atualizados dentro da empresa ativa.

## O que existe na tela

- titulo `Meu Perfil`;
- subtitulo com referencia a empresa ativa;
- botao para alterar senha;
- botao `Recarregar`;
- card de resumo com foto, nome, empresa, e-mail, funcao e status;
- area de upload ou remocao de foto de perfil;
- formulario `Dados pessoais`;
- campo `Nome completo`;
- campo `Nome de exibicao`;
- identificacao de nacionalidade e documento;
- botoes `Descartar` e `Salvar perfil`;
- painel LGPD para acoes relacionadas aos dados da conta.

## Como usar

1. Abra a tela para revisar seu cadastro.
2. Atualize os dados permitidos no formulario.
3. Salve as alteracoes com `Salvar perfil`.
4. Use a area da foto para enviar ou remover a imagem do perfil.
5. Se precisar, abra o dialogo de alteracao de senha no topo.

## Como fazer

### Alterar meu nome no painel

1. Acesse `https://admin.standdigital.com.br/config/meu-perfil?tab=overview&focus=perfil-dados-pessoais`.
2. Atualize `Nome completo` e, se desejar, `Nome de exibicao`.
3. Clique em `Salvar perfil`.

### Trocar a foto do perfil

1. Abra `https://admin.standdigital.com.br/config/meu-perfil?tab=overview&focus=perfil-foto`.
2. Use o componente de foto para enviar uma nova imagem.
3. Aguarde a confirmacao de upload.

### Alterar a senha

1. Abra `https://admin.standdigital.com.br/config/meu-perfil?tab=overview&focus=perfil-seguranca`.
2. Clique em `Alterar senha`.
3. Preencha as informacoes solicitadas no dialogo.
4. Confirme a troca.

## Perguntas e respostas

### Posso editar os dados de outro usuario por essa tela?

Nao. Essa tela e exclusiva para o perfil do usuario autenticado.

### O que significa status Ativo ou Pendente?

O status indica a situacao atual do cadastro do usuario dentro do ambiente da empresa.

### Preciso salvar depois de trocar a foto?

A foto segue o fluxo proprio de upload, separado do botao `Salvar perfil`.

### O campo de documento e obrigatorio?

Para salvar o perfil, a tela exige um identificador valido conforme a nacionalidade informada.
