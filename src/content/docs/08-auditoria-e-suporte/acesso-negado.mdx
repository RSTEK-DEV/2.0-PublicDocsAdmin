## Para que serve

Informa que o usuário autenticado não tem permissão para acessar a área solicitada.

## Como agir

1. Confirme se a rota exige outro perfil.
2. Volte para uma área liberada.
3. Solicite ajuste de permissão, se necessário.

## Benefício de entendimento

Essa tela ajuda a separar erro de permissão de erro técnico, evitando diagnósticos incorretos.
