Esta seção concentra a entrada da operação de projetos no painel. É aqui que a empresa revisa a base ativa de empreendimentos e decide se o próximo passo é editar um projeto existente, criar um novo cadastro ou iniciar uma expansão comercial.

## O que você resolve aqui

- localizar empreendimentos já cadastrados na empresa ativa;
- abrir rapidamente a edição de um projeto existente;
- copiar a URL pública de um empreendimento;
- entender quando a criação direta está liberada;
- seguir o fluxo comercial quando a expansão depender de contratação.

## Benefício para a operação

Uma base de empreendimentos bem administrada reduz duplicidade, acelera atualização de projetos e deixa mais clara a diferença entre operação já contratada e expansão ainda dependente de aprovação comercial.
