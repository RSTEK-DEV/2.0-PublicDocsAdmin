Esta seção reúne os recursos usados para sustentar apresentação comercial, distribuição de materiais e roteiros de atendimento do empreendimento. Aqui o foco é manter a base comercial do projeto pronta para uso pelo time.

## O que você resolve aqui

- organizar a biblioteca de mídias do empreendimento;
- manter peças compartilháveis para divulgação;
- criar playbooks de atendimento;

## Benefício para a operação

Quando essa camada está bem cuidada, a operação comercial ganha consistência, reduz tempo de procura por materiais e melhora a qualidade do atendimento ligado ao empreendimento.
