**Rota:** `https://admin.standdigital.com.br/standDigital/contrate`

## Para que serve

Orienta a contratação comercial de novos projetos quando a criação direta não está liberada.

## Como usar

1. Abra a tela quando precisar ampliar a operação.
2. Clique em `Contratar via WhatsApp`.
3. Continue o atendimento comercial no canal aberto.

## Benefício de uso

Essa tela separa claramente o que é cadastro operacional do que é expansão comercial, evitando confusão entre criação técnica e contratação de novo projeto.
