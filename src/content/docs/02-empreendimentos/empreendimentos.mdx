## Para que serve

É a tela principal de consulta e entrada para edição dos projetos.

## Como usar

1. Use a busca por nome ou cidade.
2. Aplique filtros por país e estado.
3. Abra o card do projeto desejado.
4. Copie a URL pública quando precisar compartilhar.

## O que você encontra

- grid de cards dos empreendimentos;
- selo de status;
- indicação de `TRIAL`, quando aplicável;
- atalhos para copiar link e editar.

## Benefício de uso

Essa tela centraliza o portfólio ativo da empresa e acelera tanto a manutenção dos projetos quanto o acesso ao material público.
