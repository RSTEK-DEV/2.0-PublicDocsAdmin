## Para que serve

Esta é a tela principal de consulta da carteira de empreendimentos. Ela funciona como ponto de entrada para edição, revisão rápida de status e acesso ao link público de cada projeto.

## O que você encontra

- campo de busca por nome ou cidade;
- filtros por país e estado ou região;
- botão `Novo Projeto`, quando o perfil permite criação direta;
- grid de cards dos empreendimentos da empresa ativa;
- selo de situação, como ativo ou inativo;
- indicação de `TRIAL`, quando aplicável;
- atalhos para copiar link, editar e revisar plano ou status.

## Como usar

1. Abra a tela para visualizar os empreendimentos da empresa ativa.
2. Use a busca e os filtros para reduzir a lista até o grupo relevante.
3. Clique no card do projeto ou no atalho de edição para seguir para a configuração.
4. Use o ícone de cópia quando precisar compartilhar a URL pública.
5. Se o perfil for master, revise plano e status diretamente pelo atalho financeiro.

## O que a tela ajuda a decidir

<Aside type="tip" title="Leitura rápida">
  Se nenhum projeto aparecer, vale validar primeiro se a empresa ativa está correta ou se os filtros aplicados não eliminaram todos os resultados.

## Benefício de uso

Essa tela centraliza o portfólio da empresa e acelera tanto a manutenção operacional quanto o acesso ao material público de cada empreendimento.
