**Rota:** `https://admin.standdigital.com.br/config/meu-perfil`

## Para que serve

Permite manter o próprio cadastro atualizado dentro da empresa ativa.

## Como usar

1. Revise os dados pessoais.
2. Atualize nome, documento e foto, quando necessário.
3. Salve o perfil.
4. Use o fluxo separado para alterar a senha.

## O que você encontra

- resumo do usuário;
- formulário de dados pessoais;
- upload de foto;
- ação de alteração de senha;
- painel de ações relacionadas à conta.

## Benefício de uso

Perfis atualizados melhoram identificação interna, evitam ruído em comunicação e ajudam a manter o acesso seguro sem depender de outro administrador para mudanças simples.
