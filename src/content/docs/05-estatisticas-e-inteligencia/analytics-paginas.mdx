**Rota:** `https://admin.standdigital.com.br/analytics/pages`

## Para que serve

Analisa desempenho das páginas do stand.

## Como usar

1. Ajuste o período.
2. Revise visualizações e tempo médio.
3. Consulte a tabela de páginas populares.
4. Selecione uma página para aprofundar a leitura.

## Como interpretar

- muita visualização com pouco tempo indica leitura superficial;
- pouco volume com muito tempo pode mostrar conteúdo relevante para nicho específico;
- páginas importantes com baixa visibilidade merecem revisão de destaque na jornada.

## Benefício de uso

Ajuda a melhorar conteúdo, organização do menu e posicionamento de informações estratégicas no stand.
