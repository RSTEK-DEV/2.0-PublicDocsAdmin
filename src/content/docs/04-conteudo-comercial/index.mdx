Esta seção cobre os ativos usados para apresentação, distribuição e apoio comercial.

## Você vai aprender

- como manter a biblioteca de mídias do empreendimento;
- como separar materiais estruturais de compartilháveis;
- como montar playbooks de atendimento;
- como usar ferramentas beta de apoio comercial.

## Benefício para a operação

Quando o conteúdo está organizado, o time comercial trabalha com mais rapidez, consistência de mensagem e melhor aproveitamento do material disponível.
