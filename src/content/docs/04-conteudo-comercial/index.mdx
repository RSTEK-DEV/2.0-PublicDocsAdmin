Esta seção cobre ferramentas auxiliares de produção comercial.

## Você vai aprender

- como usar ferramentas beta de apoio comercial.
- como gerar resumo comercial com apoio de IA;

## Benefício para a operação

Quando essas ferramentas são bem usadas, o time comercial produz comunicação mais rápido e parte de uma base mais consistente.
