## Para que serve

É a base cadastral do empreendimento.

## O que você configura

- nome e descrição;
- slug público;
- localização;
- imagens e identidade visual;
- facilidades do projeto;
- ativação do empreendimento.

## Como usar

1. Abra a aba correspondente ao tipo de dado.
2. Faça as alterações necessárias.
3. Salve pela barra superior.
4. Revise as pendências antes de ativar.

## Benefício de uso

Uma ficha técnica completa melhora apresentação comercial, consistência da marca e prontidão do projeto para publicação.

## Atenção

O status de ativação depende do cumprimento de requisitos mínimos. O painel bloqueia a ativação quando ainda existem pendências.
